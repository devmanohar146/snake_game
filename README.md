# 🐍 Snake Game (Canvas + JavaScript)

A fully functional and visually enhanced Snake Game built using **HTML5 Canvas** and **vanilla JavaScript**. This project demonstrates core game development concepts such as game loops, collision detection, state management, and UI rendering—without relying on any external libraries.

---

## 🚀 Features

* 🎮 Smooth snake movement using keyboard controls
* 🍎 Dynamic food generation aligned to grid
* 📈 Score tracking with high score system
* 💀 Collision detection:

  * Wall collision
  * Self collision
* 🔁 Restart functionality (no page reload)
* 🎨 Enhanced UI:

  * Rounded snake segments
  * Animated food (pulse effect)
  * Grid background
  * HUD-style score panel
  * Game Over overlay screen

---

## 🧠 Concepts Covered

This project is a practical implementation of:

* Game loop using `setInterval`
* State management in JavaScript
* Array-based movement (snake body logic)
* Event handling (`keydown`)
* Canvas rendering (`fillRect`, `arc`, custom shapes)
* Collision detection algorithms
* UI rendering on canvas
